# Coloroo — règles de confidentialité

Les pages publiées de la politique de confidentialité du jeu **Coloroo**
(`com.excelltech.coloroo`), servies par GitHub Pages.

| | |
| --- | --- |
| Français | https://rimka-dev.github.io/coloroo-privacy/confidentialite.html |
| English | https://rimka-dev.github.io/coloroo-privacy/privacy.html |
| Español | https://rimka-dev.github.io/coloroo-privacy/privacidad.html |

Ce dépôt ne contient **que ces pages**. Le code du jeu vit ailleurs, dans un
dépôt privé.

La Play Console exige une URL active, publiquement accessible, non
géo-restreinte, sans PDF et non modifiable : d'où un dépôt public dédié,
plutôt que d'ouvrir celui du jeu.

La source de ces pages est `docs/` dans le dépôt du jeu — **c'est là qu'on les
modifie**, puis on recopie ici.
